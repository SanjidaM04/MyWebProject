TechEase Gadgets Product Showcase
================================

Files
-----
- index.html — main page with header, featured products, comparison table, notice, and footer.
- styles.css — global styles that fulfill all assignment requirements such as unit usage, pseudo-elements, attribute selectors, layout, and responsive media queries.
- images/ — locally generated placeholder JPEGs in large and small sizes for the three featured products.
- assets/sale-ribbon.png — decorative ribbon displayed on the featured product card.

How to View
-----------
Open index.html in any modern browser. All links are internal placeholders and images are local, so no network connection is required.
